Until now, `whoisdustin` was exactly one file: a README with a resume on it. Useful as a quick bio, but it only ever showed one side of things — the job titles, not the actual work, and definitely not the woodworking.

I run a security and IT operations team by day and a small CNC/laser woodworking business (Shop Humble) on the side, and I wanted a place that could hold both without one looking like an afterthought bolted onto the other. So this is now a real site: an [About](/about/) page in an actual voice, a condensed [Experience](/experience/) page for anyone who still wants the resume view, a [Projects](/projects/) section split between Shop Humble builds and security/IT side projects, and this [Notes](/notes/) section for shorter, less formal updates.

It's built with Astro, deployed automatically to GitHub Pages on every push, and the whole point is that adding new content going forward should be as easy as writing a markdown file and pushing — not a redesign every time. First real content going up here as I get project photos and write-ups together.
